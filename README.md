# Explainable Credit Risk Prediction

**A decision-support demo that compares classifiers, explores a risk cutoff, and explains individual model scores with SHAP.**

> **Synthetic-data notice:** Every profile and outcome is generated by this project for demonstration. The app is not for real underwriting or lending decisions. Its scores are not evidence of real-world performance or fairness.

## Why this project

Credit-risk models can look accurate while hiding the business effect of a classification cutoff. This project puts the model comparison, the threshold trade-off, and a local explanation in one Streamlit experience so a reviewer can question how a score was produced.

## What you can explore

- Compare Logistic Regression, Random Forest, and XGBoost on the same stratified holdout split.
- Review precision, recall, F1, ROC AUC, and Brier score at a clearly stated 0.50 default cutoff.
- Adjust a separate maximum-risk cutoff and compare the eligible share with observed defaults in that simulated group.
- Edit a sample profile and inspect feature-level SHAP contributions.
- Download the generated synthetic dataset for local inspection.
- Read the data card and interview guide before presenting the project.

## Run locally

```bash
python -m venv .venv
# Windows PowerShell
.venv\Scripts\Activate.ps1
# macOS / Linux: source .venv/bin/activate
python -m pip install -r requirements.txt
streamlit run app.py
```

The demo generates 5,000 fictional records at startup with fixed seed `42`; there is no private dataset to download or configure. XGBoost is included in `requirements.txt`. If it is unavailable, the app still runs the Logistic Regression and Random Forest comparison.

To save a local best-model artifact and a holdout-metrics file:

```bash
python train.py
```

Generated files go into `artifacts/`, which is excluded from version control.

## Deployment

The repository is structured for Streamlit Community Cloud: push it to GitHub, create a new app from the repository, select `app.py`, and keep `requirements.txt` at the repository root. The app does not need secrets or external data access.

## How the demo works

1. Generate a deterministic synthetic dataset from the documented formula in [`credit_risk/data.py`](credit_risk/data.py).
2. Make a 75/25 stratified train/holdout split.
3. Fit Logistic Regression, Random Forest, and XGBoost when the dependency is available.
4. Compare metrics at a fixed threshold so the comparison has one consistent reference point.
5. Use an independent adjustable risk cutoff for the approval simulation.
6. Explain a profile with Tree SHAP for tree models or Linear SHAP for Logistic Regression.

The threshold chart uses the observed labels in the synthetic holdout group, not predicted labels, for its “defaults among eligible” rate. The fitted models, target formula, and profile generator all describe an invented distribution, so these figures are teaching aids only.

## Responsible-use boundary

This is a portfolio prototype only. Do not use it to approve, decline, price, rank, or otherwise assess real applicants. A real lending system would require authorized and representative data, temporal and external validation, calibration, leakage checks, subgroup and fairness analysis, explainability review, legal and policy review, monitoring, and human governance. SHAP describes model behavior under its assumptions; it is not causal evidence.
